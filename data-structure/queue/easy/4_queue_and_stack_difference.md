What is the difference between a queue and a stack?

Feature	                             Queue	                                                        Stack
Order	                    FIFO (First In, First Out)	                                   LIFO (Last In, First Out)
Insertion	                Elements are added at the rear (enqueue).	                   Elements are added at the top (push).
Deletion	                Elements are removed from the front (dequeue).	               Elements are removed from the top (pop).
Access	                    First element inserted is processed first.	                   Last element inserted is processed first.
Use Cases	                Scheduling, request handling, BFS, message queues.	           Backtracking, undo operations, function calls (recursion).
Real-World Analogy	A       queue at a ticket counter (first person served first).	       A stack of plates (last plate placed is removed first).
